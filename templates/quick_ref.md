# HTML PPT 速查卡

## 🚀 启动工作流

| 步骤 | 说明 |
|------|------|
| 1 | 拿到/共建 Markdown 文档 |
| 2 | 确认页数、配色、图片清单 |
| 3 | 逐页生成 `slide_01.html` ~ `slide_NN.html` |
| 4 | 运行 `python3 merge_slides.py`（合并版会统一管理页数） |
| 5 | 运行 `python3 templates/create_deck_editor.py output/all_slides.html` 生成审阅编排版 |
| 6 | 交付 `all_slides.html` + `all_slides_editor.html` |

## 🎬 动画（默认关闭）

模板中动画已注释。需要时在 CSS 中取消注释，然后用 `anim-1` ~ `anim-3` 类名。

> ⚠️ 合并后 iframe 内动画容易导致布局偏移，内容页建议不加。

## ⚠️ 核心禁忌

| ❌ 禁止 | ✅ 必须 |
|---------|---------|
| 用户只让删页/换页/改字时重建整份 PPT | 进入“局部手术模式”，只改目标 HTML 的目标块 |
| 从其他 PPT、旧版本、备份里擅自拼内容 | 目标 HTML 是唯一真相源，除非用户明确要求恢复 |
| 删页/换页后只改 iframe，不查页码 | 同步检查外层总页数、`#counter`、iframe id、内部 `x / y` 页码 |
| 为了修导航顺手换一套脚本/样式 | 保留原导航逻辑，只改必要的 `total`、`counter`、id |
| 不要把多页 CSS 直接拼在一起（会串色） | 合并必须用 `iframe + srcdoc` |
| 不要把图片单独发给别人（会丢图） | 图片必须 Base64 内嵌 |
| 默认模式关键布局用 `vw`/`vh` 各自响应 | 按 `1600×900` 舞台用 `px` 排版，整体缩放 |
| 每页随机新建版式 | 同一类型页面复用同一模板 |
| 为了塞内容缩小字号 | 标题 `32px~36px`，正文 `18px~22px`，内容多就拆页 |
| 每页堆太多内容 | 每页最多 3 个信息块，每块最多 3 条要点 |
| 文字贴边、重叠、溢出 | 页面四周保留安全边距，输出前逐页检查 |
| Reveal.js 逐个改 `section transform` | 用 Reveal 自带缩放，resize/fullscreen 后调用 `Reveal.layout()` |
| 每页都加动画（合并后容易偏移） | 默认不加，需要时取消注释 |
| — | 迭代先改 MD，再同步 HTML |

## ✅ 交付前检查

| 检查项 | 标准 |
|--------|------|
| 生成文件 | 必须有 `output/all_slides.html` |
| 离线资源 | 本地图片必须已 Base64 内嵌 |
| 翻页 | `→` / `←` / `Space` / `Home` / `End` 可用 |
| 全屏 | `F` 可切换全屏 |
| 路径 | 不残留 `/Users/...`、`C:\...` 等本机绝对路径 |
| 页面 | 封面、内容页、结束页均非空白且无明显溢出 |
| 逐页版式 | 标题位置、字号、边距、色彩、对齐方式统一 |
| 内容控制 | 每页主信息清楚，正文不超过约 120 字 |
| 叠页 | 跳到中间页/末页时只能看到当前页，不能出现多页重叠 |

## ✂️ 已生成 HTML 的局部手术模式

适用场景：用户说“删第 N 页”“交换第 N/M 页”“只改这一页文字”“其他不要动”。

| 步骤 | 要做什么 |
|------|----------|
| 1 | 只读取用户点名的 HTML 文件，不引用其他 deck |
| 2 | 解析实际页面容器：`iframe.frame[srcdoc]` 或 `.slide` |
| 3 | 删除/交换/替换目标块，保留其他块原样 |
| 4 | iframe 合并文件要把外层 id 重新连续为 `f1...fN` |
| 5 | 更新外层 `#counter` 与脚本 `total` |
| 6 | 检查并修正可见页脚 `x / y`；内容标题里的“第 N 页”不主动改，除非用户要求 |
| 7 | 复核页数、目标页、页码、翻页键和全屏键 |

## 🧩 交互式编排器

适用场景：用户希望自己拖拽调整页面顺序、删除页面、轻微改字改字号，并自动重算页码。

| 工具 | 用法 |
|------|------|
| `templates/deck_editor.html` | 浏览器打开后选择合并 HTML，拖拽页面卡片；点“编辑”可改某页文字/字号/字体/删选中内容；最后导出新 HTML |
| `templates/create_deck_editor.py` | 为某个具体 deck 生成已预载的 `_editor.html`，双击即用 |

| 自动处理 | 说明 |
|----------|------|
| iframe 顺序 | 按拖拽结果重排 `iframe.frame` |
| iframe id | 自动变成连续的 `f1...fN` |
| 外层页码 | 更新 `#counter` 和脚本 `total` |
| 内部页脚 | 可选更新页面内可见 `x / y`，默认关闭，且只处理明确的页脚元素 |
| 单页轻编辑 | 只重新序列化用户点“编辑/保存”的那一页 |

> 编排器不是完整设计器。它适合错字、少量删减、局部字号/字体调整；复杂版式、图表、整页重写仍应回到 Markdown/单页 HTML 重新生成。导出前若正文里有业务数字如 `3 / 5`，关闭“自动修正内部页码”或导出后复核。

推荐交付习惯：每次正式 PPT 旁边都放一个同名 `_editor.html`。正式演示打开 `all_slides.html`；想自己调顺序、删页、看缩略图、微调文字时，双击 `_editor.html`。
